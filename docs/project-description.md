# Objetivo

Desenvolver uma solução prática para um problema de Visão Computacional à escolha do aluno.

# Formato

O trabalho pode ser realizado individualmente ou em grupo de até 5 integrantes.

A base de dados pode ser escolhida livremente. Em breve, serão disponibilizadas sugestões de datasets, mas não há obrigatoriedade de utilizá-las.

É permitido o uso de qualquer linguagem ou ferramenta (Python, R, Julia, etc.).

# Entrega

O prazo será de aproximadamente 1 mês após o término das aulas.

A entrega deve conter:

- Descrição clara do problema abordado;
- Descrição da base de dados utilizada;
- Metodologia adotada;
- Relato dos experimentos realizados;
- Análise dos resultados e conclusões.

Caso a entrega seja feita exclusivamente via notebook, é obrigatório incluir células de texto explicando todos os itens acima.
